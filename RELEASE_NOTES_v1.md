# v1

The first release.

**Download:** `World of Warplanes for Mac v1.dmg` (765 MB)
**SHA-256:** `9cc01508a18d1eb804e160b3aae70ac190affc0fa905004bc7055a85baf38b1c`

## What it had

- A Wineskin wrapper with CrossOver 23.7.1 Wine
- Graphics through WineD3D (OpenGL)
- The Flight Deck setup app and the Pilot's Manual

## Known limits

- Graphics run through OpenGL, which is slower than DXVK
- No Low Power, no resolution matching, no Game Mode
